PathwayHQ Mobile — Asset Placeholders
======================================

The following image assets must be added to this directory before building:

  icon.png           — App icon (1024x1024 px, no transparency, PNG)
  splash.png         — Splash screen image (1242x2436 px recommended, PNG)
  adaptive-icon.png  — Android adaptive icon foreground (1024x1024 px, PNG with transparency)
  favicon.png        — Web favicon (196x196 px, PNG)

Design guidelines:
  - Primary brand colour: #10b981 (emerald green)
  - Use the Zap icon (lightning bolt) as the central motif
  - Icon background: solid #10b981
  - Splash background: #10b981 (already configured in app.json)

You can generate placeholder assets with Expo's asset generator:
  https://docs.expo.dev/guides/app-icons/

Or use a design tool such as Figma, Sketch, or Canva to create properly
sized assets before submitting to the App Store / Google Play.
